# CubeMethod Discovery

探索考虑人类执行成本的、可解释的三阶魔方分阶段还原策略。

## 当前状态

项目处于规划与基础学习阶段。已建立实验记录方案；尚未实现魔方模拟器、运行搜索实验或获得性能结论。

## 研究问题

- 使用人类操作成本代替纯步数成本，是否会改变搜索偏好的路径和中间目标？
- 自动筛选的中间结构与已有方法有什么相似或不同？
- 模拟评价与真实人类执行之间有哪些差异？

当前优先完成正确的模拟器和小规模搜索，再开展成本与结构比较。发现比现有方法更快的策略是探索目标，尚无证据支持。

4. 每周总结一次，完成里程碑后更新本页。

## 本人参与和 AI 辅助

本人先思考、推导、实现核心算法和分析结果；AI 提供分级提示、代码审查及重复劳动辅助。分别记录本人贡献和 AI 帮助，并用独立任务检查理解。

## 结论边界

人工成本模型是代理指标，未经实际测量校准不能解释为秒数。随机转动序列不等于均匀随机状态。失败与超时保留；最终测试集不参与筛选与调参。当前没有“重新发现已有方法”或“超越 Roux / CFOP”的实验结论。
